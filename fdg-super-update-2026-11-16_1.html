Weekly AI briefing
FDG Super Update
Week of 9 November 2026 to 16 November 2026 (NZ time)

A heavy week for Anthropic, with a new flagship model, a manufacturing plugin and a meeting assistant. Google shipped a cheaper fast model and team Skills in Workspace, and agents that spend money or make calls for you moved closer to the mainstream. Microsoft Ignite runs 17 to 20 November, so expect a large batch of Copilot news next week.

Top 5 this week

01Anthropic released Claude Fable 5.2 on 9 Nov. It is now Claude's top generally available model and the default in Claude Code, with gains in coding, reasoning and vision. API pricing is US$8 / US$40 per million input / output tokens. Source
02Claude for Manufacturing launched on 12 Nov. It is a plugin with 17 skills and connectors to Autodesk Fusion, Infor, Microsoft 365 and NetSuite, and the closest thing yet to an off-the-shelf AI kit for a business like FDG. Source
03Google launched Gemini 4 Hydrogen on 12 Nov. It is a fast, cheaper model for agent tasks, now in the Gemini app and Search for all users. Workspace is also rolling out Skills, so teams can make Gemini follow their own templates and rules. Google · Workspace
04Copilot's paid agent features will soon be visible to every licensed user. Microsoft says Cowork, Code and Autopilot will show as "Request access" for anyone with a Microsoft 365 Copilot licence, with a new admin setting arriving mid-November. Separately, Microsoft cloud prices in NZD change on 1 Jan 2027. Message Center · Microsoft
05Agents that act and spend for you moved forward. ChatGPT Wallet lets OpenAI's "dots" agents buy things for some US Pro users, with each purchase approved by Face ID or fingerprint, and Meta's Muse can now phone US businesses for paying users. TechCrunch · TechCrunch

AI at FDG

Finance

  • Month-end variance commentary. Copilot in Excel can now save a reusable skill (for example a variance analysis routine) and shows its plan before it edits. Use it to draft margin commentary by product family each month for a person to check. First step: Write the steps finance already follows for one month-end report as a skill and run it on last month's file. Source
  • Pricing and margin model checks. Claude for Excel can audit a workbook for formula errors and flag hardcoded assumptions. Point it at the price list and margin models before the next price review. First step: Run an audit on one pricing workbook and compare what it finds with what finance already knew. Source

Technical

  • Standards-based checking assistant. ENEOS Materials built a custom GPT on its own standards that turns inputs into design specs and flags risks in seconds. FDG could do the same for bracing selection checks against its own design guides, with an engineer signing off every answer. First step: Load one product range's design guide and test reports into a ChatGPT custom GPT or Claude project and test it on 20 past technical queries. Source
  • Engineering knowledge for newer staff. WSP is piloting an AI built on senior specialists' knowledge so junior engineers get fast answers to technical questions. First step: Have a senior engineer write answers to the 30 most common technical support questions and use them as the knowledge source for a Copilot agent in Teams. Source

Marketing

  • Technical newsletters and landing pages. Distributor Esprinet uses Copilot to draft newsletters and landing pages, cutting production from about a day to minutes. First step: Give Copilot or Claude a MODFRAME product sheet and FDG's tone guide and draft next month's engineer newsletter from it. Source
  • Showing up in AI answers. Engineers increasingly ask AI assistants for product options. HubSpot says customers using its answer-engine optimisation (AEO) tools generate nearly 3x more MQLs (HubSpot's own figures). First step: Ask ChatGPT, Claude and Gemini five questions an engineer would ask about seismic bracing in NZ and record whether FDG appears. Source

Operations

  • Supplier order-status chasing. GE Appliances uses a Gemini Enterprise agent to handle order-status questions with 600+ suppliers and cut backorders by 25%. First step: List the 10 suppliers with the most late orders and build a Copilot prompt that turns the open-PO report into chase emails. Source
  • Purchase requests in monday.com. monday.com's agents can process purchase requests and update boards within existing permissions, and connect to ChatGPT, Claude and Copilot. First step: Map the current purchase-request steps on one monday.com board and test one agent on the approval routing. Source

Customer service

  • Website product and order agent. Industrial manufacturer Regal Rexnord's agent answers from product specs and documents, checks order status and hands off to live chat, serving 1,000+ users a week. First step: Collect the 50 most common customer questions from email and phone logs to define what such an agent would need to answer. Source
  • HubSpot Customer Agent with safe escalation. Adhesives maker Seal Bond trained a Breeze Customer Agent on its technical data sheets and set it to escalate technical requests rather than make unverified claims. First step: Trial Customer Agent on non-technical queries only (stock, lead times, where to buy). Source

Sales

  • Visit notes straight into the CRM. Esprinet's sales agent turns reps' voice notes after customer visits into CRM entries, saving 15 to 20 minutes per visit. First step: Have two reps dictate post-visit notes into Copilot or ChatGPT on their phones and paste a structured summary into HubSpot for two weeks. Source
  • Meeting prep and forecasting in HubSpot. Motion-control manufacturer Aerotech uses Breeze Assistant for meeting prep, summaries and forecasting, and reports its win rate rose from 15% to 25%. First step: Use Breeze to prepare briefs for the next five consulting engineer meetings. Source

Trends and best practice

  • Usage is not the same as value. McKinsey finds 80% of respondents report personal productivity gains but only 37% see any EBIT impact; high performers redesign whole workflows. Pick a few processes and redesign them end to end. Source
  • Agent governance trails agent plans. Gartner reports 71% of CIOs plan to deploy agentic AI within 12 months but only 21% have governance for it. Set rules on what agents can read, send and spend before switching them on. Source
  • Training is the bottleneck. BCG finds 72% of workers say their needed skills have shifted but only 36% feel adequately upskilled, and two-thirds get no guidance on using the time AI saves. Source
  • Share agents across a team. Anthropic research found teams did worse when each person had their own agent than when the team shared one. Build shared projects or agents per team rather than many personal ones. Source
